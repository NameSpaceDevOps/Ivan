# راهنمای ارتقا و به‌روزرسانی سامانه ایوان (Ivan Upgrade Guide)

این راهنما مراحل به‌روزرسانی امن ایوان به نسخه‌های جدیدتر، اعتبارسنجی پایگاه‌داده و نحوه بازگردانی در شرایط اضطراری (Rollback) را شرح می‌دهد.

---

## ۱. قبل از به‌روزرسانی: تهیه نسخه پشتیبان (Backup)

پیش از دریافت نسخه جدید یا جایگزینی فایل‌های اجرایی:
1. وارد سامانه شده و به بخش **بیشتر -> پشتیبان‌گیری، درون‌ریزی و هوش مصنوعی (`/settings`)** بروید.
2. دکمه **«تهیه نسخه پشتیبان آنی»** را بزنید تا اسنپ‌شات آنلاین غیرمسدودکننده از SQLite با دستور `VACUUM INTO` گرفته شود.
3. دکمه **«تست سلامت»** را بر روی فایل جدید بزنید تا نتیجه `PRAGMA integrity_check` و تعداد رکوردهای ثبت‌شده تایید گردد.
4. دکمه **«دریافت فایل فشرده (ZIP) خانوار»** یا **«دریافت فایل JSON کامل»** را بزنید تا یک کپی آفلاین در سیستم شخصی خود داشته باشید.

---

## ۲. ارتقای سرویس ویندوز (Windows Service Upgrade)

1. متوقف کردن موقت سرویس:
   ```cmd
   sc.exe stop Ivan
   ```

2. انتشار نسخه جدید و جایگزینی فایل‌ها:
   ```powershell
   dotnet publish src/Ivan.Web/Ivan.Web.csproj -c Release -o C:\Services\Ivan_New
   # فایل‌های پوشه C:\Services\Ivan_New را در C:\Services\Ivan کپی کنید (دایرکتوری app_data دست‌نخورده باقی می‌ماند).
   ```

3. راه‌اندازی مجدد سرویس:
   ```cmd
   sc.exe start Ivan
   ```

4. بررسی لاگ‌ها در مسیر برنامه و وضعیت سلامت با فراخوانی:
   ```
   http://localhost:5000/healthz
   ```

---

## ۳. ارتقا با Docker Compose

1. دریافت آخرین تغییرات و بازسازی کانتینر:
   ```bash
   git pull
   docker compose down
   docker compose up -d --build
   ```

2. بررسی لاگ سرویس:
   ```bash
   docker logs -f ivan-app
   ```

---

## ۴. بازگردانی اضطراری (Emergency Rollback)

اگر پس از ارتقا خطایی رخ داد:
1. سرویس را متوقف کنید.
2. به پوشه `app_data/backups/` بروید و آخرین فایل با نام `ivan_backup_YYYYMMDD_HHmm.db` را پیدا کنید.
3. فایل را به `app_data/ivan.db` تغییر نام داده و جایگزین کنید.
4. سرویس را مجدداً روشن کنید.
